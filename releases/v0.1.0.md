# v0.1.0

## What changed

- Initial focused release of `agent-context-lab`.
- Adds `scan`, `score`, `map`, `mcp`, and `brief` CLI commands.
- Detects conflicting agent instructions, stale context markers, duplicate guidance, context budget overflow, invalid MCP JSON, and risky MCP server config.
- Supports Markdown and JSON output.
- Supports deterministic CI gating through `--fail-under`.

## Try it

```bash
PYTHONPATH=src python3 -m agent_context_lab scan examples/conflicting-agent-repo --format markdown
```

## Notes

- This release is intentionally small and standard-library only.
- Please open issues with concrete examples and expected output.
