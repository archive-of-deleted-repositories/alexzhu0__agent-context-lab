# v0.1.1

## What changed

- Hardens the CI contract after the first review pass.
- Adds top-level `scan_error` to Markdown, full JSON, and command-specific JSON outputs.
- Marks scan-fatal findings with explicit `is_scan_error` metadata so CI behavior is not coupled to rule ID strings.
- Returns exit code `1` for deterministic scan/read/MCP config failures before applying `--fail-under`.
- Prunes ignored trees before descent so large dependency, VCS, virtualenv, and build directories are not materialized.
- Keeps `brief --max-chars` within the requested limit even for tiny budgets.
- Expands regression coverage from 41 to 49 tests.

## Try it

```bash
PYTHONPATH=src python3 -m agent_context_lab scan examples/conflicting-agent-repo --format markdown --fail-under 50
```

## CI contract

```text
0 = clean scan and score passed
1 = scan/read/config error
2 = clean scan but score below --fail-under
```

## Notes

- This remains standard-library only and local-first.
- Use this release if you want `agent-context-lab` as a reliable GitHub Actions gate.
